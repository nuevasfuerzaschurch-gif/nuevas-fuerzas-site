# Agent Rules - Nuevas Fuerzas

- Trabajar únicamente en `development`.
- Nunca hacer push directo a `main`.
- Nunca hacer merge automático.
- Siempre entregar enlace directo al Pull Request.
- No tocar Vercel, DNS ni formularios sin autorización explícita.
- No mezclar proyectos externos como COLP/Vite.
- La fuente oficial actual es `version-inicial/`.
- `npm run build` debe copiar exclusivamente `version-inicial/` a `dist/`.
- Detenerse si hay cambios locales no relacionados.
- Antes de editar, identificar archivos exactos.
- No borrar archivos sin aprobación humana.
